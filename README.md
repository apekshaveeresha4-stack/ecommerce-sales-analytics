# E-Commerce Sales Analytics Dashboard

## Overview

This project analyzes e-commerce sales data to identify trends in sales, profitability, customer segments, products, and geographic performance.

The project uses SQL for data analysis and Excel for data cleaning, PivotTable analysis, visualization, and dashboard creation.

## Tools & Technologies

* SQL
* Microsoft Excel
* Excel PivotTables
* Excel Charts
* Data Cleaning
* Exploratory Data Analysis

## Dataset

The dataset contains information about:

* Customers
* Products
* Orders
* Customer segments
* Product categories
* Geographic information
* Sales and profit

## Analysis Performed

### Sales Performance

* Overall sales and profit analysis
* Monthly sales trends
* Category-wise sales and profitability
* State-wise sales performance

### Product Analysis

* Top-selling products
* High-sales/low-margin products
* Product-level profitability

### Customer Analysis

* Customer segment performance
* Repeat customer analysis
* Customer purchasing behavior

### Discount Analysis

* Sales and profitability across discount levels
* Profit-margin comparison between discount categories

## Key Insights

* Home Appliances was one of the strongest-performing product categories by sales.
* July recorded the highest monthly sales and profit in the analyzed period.
* November recorded the lowest monthly sales.
* Maharashtra was the highest-performing state by sales.
* Some high-sales products had considerably lower profit margins than other products.
* 133 customers were identified as repeat customers in the SQL analysis.
* Profit margins remained relatively stable across the analyzed discount levels.
